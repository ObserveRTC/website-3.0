Use the browser first: attach Client Monitor to a connection your application already uses, inspect receiving/sending measurements, then decide whether to send samples to a backend.

1. [Monitor your first connection](/docs/overview/introduction/).
2. [Inspect monitoring results](/docs/getting-started/results/).
3. [Send samples to your backend](/docs/getting-started/backend/) when you need server analysis.

You need an application with a live `RTCPeerConnection` and a browser environment. Client Monitor does not create the media session for you. The quick start uses npm's current release; version-specific references are documented in [compatibility](/docs/reference/versions/).
