`@observertc/client-monitor-js` runs in your browser. It adapts `getStats()` reports, maintains a linked monitor graph, calculates interval metrics and runs detectors. Use it on its own or send samples to Observer.

This reference covers **4.9.1** with schema **3.7.0**.
