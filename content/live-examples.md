## WebRTC-Observer

WebRTC-Observer is a demo of [Client Monitor](/docs/client-monitor-js/) capabilities. Explore the signals collected from a running WebRTC connection and see client-side monitoring in action.

[Try WebRTC-Observer ↗](https://webrtc-observer.org/)

## Stats Dashboard

The demo at dashboard.webrtc-observer.org shows the [Stats Dashboard](/docs/stats-dashboard/) for [Observer](/docs/observer-js/). Explore how collected WebRTC statistics can be presented in a dashboard.

[Open the Stats Dashboard demo ↗](https://dashboard.webrtc-observer.org/)

## eduMEET

eduMEET is an open-source video conferencing application that integrates ObserveRTC for WebRTC monitoring. Its source code offers an example of ObserveRTC in a real application.

[Explore eduMEET on GitHub](https://github.com/edumeet/edumeet)
